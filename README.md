# ScamShield

A web application that checks messages, links, phone numbers and emails for scam signs.

## Tech Stack
- Backend: Java 21, Spring Boot, Maven
- Frontend: HTML, CSS, JavaScript (pages designed with Google Stitch)
- IDE: IntelliJ IDEA
- Version Control: Git, GitHub

## Features
- Link, message, phone and email scanner
- Dashboard, scan history and scam reports
